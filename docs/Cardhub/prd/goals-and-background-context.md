# 目标与背景 (Goals and Background Context)

## 1.1 目标 (Goals)

- 为卡牌爱好者（尤其是新手）创建一个权威、集中的信息知识库。
- 通过评论交流功能，为早期社区的形成和用户粘性的建立奠定基础。
- 通过一个轻量级的 MVP Web 应用，快速验证产品的核心价值主张。

## 1.2 背景 (Background Context)

当前卡牌市场，特别是中文环境中，存在着信息分散、质量参差不齐的痛点，新手入门门槛高，核心玩家也缺少一个将数据与交流相结合的专业平台。 Cardhub 旨在解决此问题，其 MVP 将首先通过一个专注于知识分享（卡牌数据库、系列介绍）的 Web 应用切入市场，后续计划扩展至小程序、原生 App 等全平台，并逐步增加社区论坛、交易系统等深度功能，最终成为服务于卡牌爱好者全生命周期的一站式平台。
